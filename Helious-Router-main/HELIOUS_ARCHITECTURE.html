🧮 Core Algorithms Implemented
Round-Robin Load Balancing
Type: Weighted Scheduling
Distributes API calls across 3 providers using rotation based on prompt count. Balances costs and prevents overuse.
Sequential Fallback Chain
Type: Chain-of-Responsibility
Attempts providers in sequence until one succeeds. O(1) to O(3) complexity with comprehensive error logging.
Recursive Model Fallback
Type: Model Hierarchy
For Gemini: tries gemini-2.0-flash → gemini-1.5-flash → gemini-pro. Ensures availability through graceful degradation.
Session Management
Type: File-Based State
O(1) creation (unshift), O(n) lookup/deletion. Persistent storage with JSON serialization and auto-recovery.
Append-Only Event Logging
Type: Timestamped Log
O(1) per entry. ISO 8601 timestamps. No file rewrites. Real-time monitoring dashboard support.
Polling-Based Monitoring
Type: React Polling Hook
2-second interval log fetching. Filters empty lines. Auto-cleanup on unmount. O(g) complexity.
